## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PATCH /overrides request body → store writer | source_lang_override elements must be validated as 2-letter language codes before persistence |
| model_override string → LLM endpoint | model name is an opaque string; no validation against endpoint; invalid values fail at translation time |
| LLMClient semaphore → concurrency cap | The single semaphore must not be duplicated by model-override code paths |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-06 | Tampering | PATCH /series/{id}/overrides — source_lang_override | mitigate | Validate each element matches regex ^[a-z]{2}$ before store call; 422 on invalid codes (ASVS V5 L1; prevents arbitrary string injection into the selection pipeline) |
| T-10-07 | Tampering | PATCH /series/{id}/overrides — model_override | mitigate | Pydantic type validation (str | None) ensures non-string values are rejected at deserialization; length is implicitly bounded by Pydantic str type; no server-side length enforcement in v1 (model IDs are opaque, D-RESEARCH open question) |
| T-10-08 | Elevation of Privilege | D-06 single-semaphore violation | mitigate | Plan action explicitly prohibits creating a second LLMClient or second asyncio.Semaphore; verify acceptance criteria enforces grep check |
| T-10-09 | Information Disclosure | BibleEvent audit record contains model_override | accept | BibleEvent is an internal audit table on the operator's own SQLite DB; no external disclosure |
