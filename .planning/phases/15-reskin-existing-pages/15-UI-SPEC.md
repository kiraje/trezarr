## Typography

Inherited verbatim from Phase 11. Contract: exactly 2 weights (400 / 600).

| Role | Size | Weight | Line Height | Phase-15 usage |
|------|------|--------|-------------|----------------|
| Body | 16px (1rem) | 400 | 1.5 | Empty state body, error detail text |
| Label | 14px (0.875rem) | 400 | 1.4 | Table cell text (`text-sm`); badge labels; form field labels; log timestamps |

to match the pattern established in Phase 14 (Series.tsx uses `text-xl font-semibold`).

`CardTitle` or equivalent — matches the secondary heading role inside `<Card>`.

**Form field labels:** `text-xs` (12px) `text-muted-foreground` above inputs — matches
shadcn `Label` component default.

## Color

All color values are INHERITED from the Phase-11 CSS variables. No new hex values are
introduced in this phase.

| Role | CSS Variable | Approx Value | Usage in this phase |
|------|-------------|--------------|---------------------|

**Accent (`--primary`) reserved for EXACTLY these elements in Phase 15:**
- The active tab underline / indicator bar on BibleEditor's `<Tabs>` switcher

- Already-established reservations: nav active bar, brand glyph, progress bar fill (Phase 14)

Accent must NOT be used for: Settings save button hover (use `hover:bg-primary/90` not
a blue hex `#2563eb`), table headers, general borders, breadcrumb link text (use

**Inline status colors (semantic, NOT accent):**
- Success state (ConnectionTestButton success, Sonner success): `bg-emerald-900/50 text-emerald-400` (dark tinted green)
- Error state (ConnectionTestButton error, inline error, Sonner error): `bg-destructive/10 text-destructive`
- Warning state (UnreachableBanner, RestartBanner): `bg-amber-900/30 text-amber-400` — replaces the current `style={{backgroundColor:"#451a03", color:"#fbbf24"}}`

**All `style={{ backgroundColor: "#..." }}` inline hex must be replaced.** See token map below.

## BibleEditor Safety Rules (D-02, RSK-02 — LOAD-BEARING)

The BibleEditor is 90KB and the highest regression risk in this phase. The following
rules are NON-NEGOTIABLE. Any PR that violates them must be reverted before merge.

### The Reskin Invariant

**Token/className substitution and primitive swaps ONLY.** The executor MUST NOT:
- Change any API call (`getSeriesBible`, `patchCharacter`, `patchAddressMapPair`,
  `patchRegister`, `patchSeriesOverrides`, `addCharacter`, `addTerm`, `addAddressMapPair`,
  `deleteTerm`, `deleteAddressMapPair`, `getPronouns`, `getSettings`)
- Change the `locked` / `lock_state` / `provenance` field semantics or how they are
  displayed (LockBadge values, provenance labels, the hard-block on lock-with-empty-term)
- Change `FieldHistoryPanel` fetch logic or the field it watches
- Change `PronounCombo` filtering logic, selection state, or the `kinship_reciprocal` behavior
- Change `ReciprocalSuggestionPanel` accept/decline logic
- Alter the five tab identifiers (`characters`, `address_map`, `terms`, `register`,
  `overrides`) or the data each tab renders
- Remove or consolidate any state variable (the dirty/saving/restart pattern per section
  must stay identical, just surfaced through shadcn primitives)

### The Five Tabs — required behavioral identity

| Tab | Behavioral invariant |
|-----|---------------------|
| Characters | Add/edit/save character name, gender, role, rough_age; lock toggle per character row; field history inline below row |
| Address Map | Directed speaker→addressee pronoun pairs; PronounCombo for self_term and address_term; hard-block lock when term is empty; ReciprocalSuggestionPanel; lock toggle |
| Term Dictionary | Source→Vietnamese term pairs; add/delete term; lock toggle per term row |
| Register | Register selector + source-language-priority selector; save per field |
| Overrides | Series-level text override fields; save button |

### Incremental section reskin strategy

Reskin BibleEditor in **five sequential sub-tasks** (one per section component), each
