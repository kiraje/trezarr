Wire the complete Phase-3 vertical slice end-to-end in a single argparse CLI entry point: `trezarr run --once`. This is the capstone plan — it calls every module built in Plans 03-02 through 03-04 in the correct order, implements the D-30 batch-run semantics (per-item quarantine, summary, exit code), and registers the console script in pyproject.toml so the command is invokable after install.

- HIGH #2: refuse startup when path_mappings is empty AND any *arr enabled (call `assert_media_roots_configured` before `probe_media_roots`)
- HIGH #6: `_run_once()` returns an `int`; `main()` does `raise SystemExit(asyncio.run(_run_once(args.config)))` — no `sys.exit()` from inside async
- HIGH #7: `LLMClient(settings)` instantiated ONLY when `eligible` is non-empty
- MEDIUM #10: `except DiscoveryError` per-service so one bad *arr does not kill the run
- MEDIUM #13: `except PermissionApplyError` quarantines the item (chmod failure path)
- MEDIUM #14: widened summary fields (`discovered=`, `eligible=`, `translate_skipped=`, `scan_skipped=`, etc.); rename internal counter `n_skip` → `n_translate_skipped`
- HIGH #4 / HIGH #5: iterate `EligibleItem` (not bare tuples); call `is_eligible(source_sub_path, ledger)` (no media_path)

    Design decisions honoured:
      D-21  One-shot CLI. No daemon, scheduler, webhook, or watcher — Phase 7.
      D-30  Per-item quarantine on failure; run continues; end summary; non-zero exit on any failure.

    Codex review fixes (03-REVIEWS.md):
      HIGH #2  assert_media_roots_configured before probe (refuse empty path_mappings when arr enabled)
      HIGH #6  _run_once() returns int; main() wraps in SystemExit
      HIGH #7  LLMClient instantiated only when eligible list is non-empty
      MEDIUM #10  except DiscoveryError per-service for per-service resilience
      MEDIUM #13  except PermissionApplyError → quarantine
      MEDIUM #14  widened summary fields
    """

    IMPORTS (per 03-PATTERNS.md §"Import block structure" — stdlib first, third-party, intra-project):
      from __future__ import annotations
      import argparse
      import asyncio
      import logging
      import sys
      from trezarr.config import TrezarrSettings
      from trezarr.llm.client import LLMClient
      from trezarr.output.ledger import Ledger
      from trezarr.paths import (
          build_media_roots,
          probe_media_roots,
          assert_within_media_roots,
          assert_media_roots_configured,
      )
      from trezarr.arr import DiscoveryError
      from trezarr.arr.sonarr import discover_sonarr_items
      from trezarr.arr.radarr import discover_radarr_items
      from trezarr.discover.scan import scan_for_eligible_items
      from trezarr.translate.engine import translate_file
      from trezarr.output.write import apply_permissions, PermissionApplyError
      logger = logging.getLogger(__name__)

    `main() -> None` (sync — the console_scripts entry point). PER 03-REVIEWS.md HIGH #6:
      - Build argparse.ArgumentParser(prog="trezarr")
      - add_subparsers(dest="command", required=True)
      - sub.add_parser("run").add_argument("--once", action="store_true", required=True)
      - run_parser.add_argument("--config", default=None)

      - if args.command == "run" and args.once:
          raise SystemExit(asyncio.run(_run_once(args.config)))
      - (NO `sys.exit()` calls anywhere else; main()-level SystemExit is the ONE translation point)

    `async def _run_once(config_path: str | None) -> int` (PER 03-REVIEWS.md HIGH #6 — returns int):

      Step 1 — Load settings + logging:
        settings = TrezarrSettings(_yaml_file=config_path) if config_path else TrezarrSettings()
        logging.basicConfig(level=logging.INFO)

      Step 2 — Startup configuration check (per 03-REVIEWS.md HIGH #2):
        # Refuses empty path_mappings when any *arr is enabled. Calls sys.exit(1)
        # if misconfigured — this is intentionally NOT recoverable since D-29 requires
        # a non-empty media_roots set for the traversal guard to be meaningful.
        assert_media_roots_configured(settings)

      Step 3 — Startup probe (D-24 fail-fast, before any API call):
        media_roots = build_media_roots(settings)
        probe_media_roots(media_roots)    ← exits if any root unreadable

      Step 4 — Discovery (D-22) with per-service resilience (per 03-REVIEWS.md MEDIUM #10):
        all_items: list = []
        discovery_failures: list[str] = []

        if settings.sonarr_enabled:
            try:
                sonarr_items = discover_sonarr_items(settings)
                logger.info("Sonarr discovered %d items", len(sonarr_items))
                all_items.extend(sonarr_items)
            except DiscoveryError as exc:
                logger.error("Sonarr discovery failed: %s", exc)
                discovery_failures.append(f"sonarr: {exc}")

        if settings.radarr_enabled:
            try:
                radarr_items = discover_radarr_items(settings)
                logger.info("Radarr discovered %d items", len(radarr_items))
                all_items.extend(radarr_items)
            except DiscoveryError as exc:
                logger.error("Radarr discovery failed: %s", exc)
                discovery_failures.append(f"radarr: {exc}")

        enabled_arr = (1 if settings.sonarr_enabled else 0) + (1 if settings.radarr_enabled else 0)
        if enabled_arr > 0 and len(discovery_failures) == enabled_arr:
            # All enabled *arr services failed → fatal for the run
            logger.error("All enabled *arr services failed: %s", "; ".join(discovery_failures))
            print(f"Run failed: all *arr discovery failed ({'; '.join(discovery_failures)})")
            return 1

        n_discovered = len(all_items)
        logger.info("Discovered %d total media items from *arr APIs", n_discovered)

      Step 5 — Gap detection / eligible items (D-25, D-26, D-27, D-28):
        ledger = Ledger(settings.translate_ledger_path)
        eligible, scan_stats = scan_for_eligible_items(all_items, settings, ledger)
        n_eligible = len(eligible)
        logger.info("%d items eligible for translation", n_eligible)

      Step 6 — LLMClient construction (per 03-REVIEWS.md HIGH #7 — ONLY if eligible):
        llm_client = None
        if n_eligible > 0:
            llm_client = LLMClient(settings)

      Step 7 — Per-item translate loop with per-item quarantine (D-30):
        n_done = 0
        n_translate_skipped = 0   ← renamed from n_skip per 03-REVIEWS.md MEDIUM #14
        n_quar = 0
        n_fail = 0
        for eligible_item in eligible:    ← iterating EligibleItem dataclasses per 03-REVIEWS.md HIGH #5
            source_sub_path = eligible_item.source_sub_path
            try:
                result = await translate_file(source_sub_path, settings, llm_client, ledger)
                if result.status == "done":
                    if result.output_path is None:
                        # Defensive assertion per 03-REVIEWS.md MEDIUM concern: "done" must have output_path
                        logger.error("Translate returned 'done' but output_path is None for %s", source_sub_path)
                        n_fail += 1
                        continue
                    # Path-traversal guard before write permission application (D-29)
                    assert_within_media_roots(result.output_path, media_roots)
                    try:
                        apply_permissions(
                            result.output_path,
                            settings.puid, settings.pgid, settings.umask,
                        )
                        n_done += 1
                    except PermissionApplyError as perr:
                        # chmod failure → item is written but unreadable → quarantine (03-REVIEWS.md MEDIUM #13)
                        logger.warning("Item quarantined due to chmod failure: %s — %s",
                                       source_sub_path, perr)
                        n_quar += 1
                elif result.status == "skipped":
                    n_translate_skipped += 1
                elif result.status == "quarantined":
                    n_quar += 1
                    logger.warning("Item quarantined by translate_file: %s", source_sub_path)
            except Exception as exc:
                logger.error("Unhandled error translating %s: %s", source_sub_path, exc)
                n_fail += 1

      Step 8 — Summary and exit code (D-30 + 03-REVIEWS.md MEDIUM #14 widened fields):
        n_scan_skipped = scan_stats.no_source + scan_stats.foreign_vi + scan_stats.already_done
        summary = (
            f"Run complete: discovered={n_discovered}, eligible={n_eligible}, "
            f"translated={n_done}, translate_skipped={n_translate_skipped}, "
            f"scan_skipped={n_scan_skipped} (no_source={scan_stats.no_source}, "
            f"foreign_vi={scan_stats.foreign_vi}, already_done={scan_stats.already_done}), "
            f"quarantined={n_quar}, failed={n_fail}"
        )
        if discovery_failures:
            summary += f"; partial-discovery-failures=[{'; '.join(discovery_failures)}]"
        print(summary)

        if n_fail > 0 or n_quar > 0:
            return 1
        return 0

The existing LLMClient semaphore handles concurrency within each translate_file() call for batch-level parallelism.     Do NOT implement any daemon, scheduler, poll loop, webhook receiver, or watchfiles integration (D-21 — all deferred to Phase 7).

The only `sys.exit` / `SystemExit` raised by this module is at `main()`'s `raise SystemExit(asyncio.run(_run_once(args.config)))`.
