    """One-shot CLI entry point: `trezarr run --once`.

    Design decisions honoured:
      D-21  One-shot CLI. No daemon, scheduler, webhook, or watcher — Phase 7.
      D-30  Per-item quarantine on failure; run continues; end summary; non-zero exit on any failure.
    """

    IMPORTS (per 03-PATTERNS.md §"Import block structure" — stdlib first, third-party, intra-project):
      from __future__ import annotations
      import argparse
      import asyncio
      import logging
      import sys
      from trezarr.config import TrezarrSettings
      from trezarr.llm.client import LLMClient
      from trezarr.output.ledger import Ledger
      from trezarr.paths import build_media_roots, probe_media_roots, assert_within_media_roots
      from trezarr.arr.sonarr import discover_sonarr_items
      from trezarr.arr.radarr import discover_radarr_items
      from trezarr.discover.scan import scan_for_eligible_items
      from trezarr.translate.engine import translate_file
      from trezarr.output.write import apply_permissions
      logger = logging.getLogger(__name__)

    `main() -> None` (sync — the console_scripts entry point):
      - Build argparse.ArgumentParser(prog="trezarr")
      - add_subparsers(dest="command", required=True)
      - sub.add_parser("run").add_argument("--once", action="store_true", required=True)
      - run_parser.add_argument("--config", default=None)
      - args = parser.parse_args()
      - if args.command == "run" and args.once: asyncio.run(_run_once(args.config))

    `async def _run_once(config_path: str | None) -> None`:
      Step 1 — Load settings:
        settings = TrezarrSettings(_yaml_file=config_path) if config_path else TrezarrSettings()
        logging.basicConfig(level=logging.INFO)

      Step 2 — Startup probe (D-24 fail-fast, before any API call):
        media_roots = build_media_roots(settings)
        probe_media_roots(media_roots)    ← exits if any root unreadable

      Step 3 — Discovery (D-22):
        all_items: list = []
        all_items.extend(discover_sonarr_items(settings))
        all_items.extend(discover_radarr_items(settings))
        logger.info("Discovered %d total media items from *arr APIs", len(all_items))

      Step 4 — Gap detection / eligible items (D-25, D-26, D-27, D-28):
        ledger = Ledger(settings.translate_ledger_path)
        llm_client = LLMClient(settings)
        eligible = scan_for_eligible_items(all_items, settings, ledger)
        logger.info("%d items eligible for translation", len(eligible))

      Step 5 — Per-item translate loop with per-item quarantine (D-30):
        n_done = n_skip = n_quar = n_fail = 0
        for item, source_sub_path in eligible:
          try:
            result = await translate_file(source_sub_path, settings, llm_client, ledger)
            if result.status == "done":
              # Path-traversal guard before write permission application (D-29)
              if result.output_path and media_roots:
                assert_within_media_roots(result.output_path, media_roots)
              apply_permissions(result.output_path, settings.puid, settings.pgid, settings.umask)
              n_done += 1
            elif result.status == "skipped":
              n_skip += 1
            elif result.status == "quarantined":
              n_quar += 1
              logger.warning("Item quarantined: %s", source_sub_path)
          except Exception as exc:
            logger.error("Unhandled error translating %s: %s", source_sub_path, exc)
            n_fail += 1

      Step 6 — Summary and exit code (D-30):
        print(f"Run complete: translated={n_done}, skipped={n_skip}, quarantined={n_quar}, failed={n_fail}")
        if n_fail > 0 or n_quar > 0:
          sys.exit(1)
        # else: fall through (implicit sys.exit(0))

    IMPORTANT sequential translate: Phase 3 translates items sequentially in the for loop (one at a time). The existing LLMClient semaphore handles concurrency within each translate_file() call for batch-level parallelism. Do NOT add a second asyncio.Semaphore around the item loop — that would double-cap and conflict with the LLM semaphore.

    Note in a comment: "# Phase 7: replace with AsyncSonarr/AsyncRadarr + asyncio.gather for parallel item discovery across large libraries".

    Do NOT implement any daemon, scheduler, poll loop, webhook receiver, or watchfiles integration (D-21 — all deferred to Phase 7).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| argparse (user CLI input) → settings | config_path flag passes user-supplied path; TrezarrSettings validates via pydantic-settings |
| assert_within_media_roots → apply_permissions | Guard fires before permissions are applied to any write path; confirmed write is within configured media roots |
| CLI process → *arr APIs | All API calls are read-only GET; no write calls to Sonarr/Radarr |
| CLI process → filesystem | All writes go through existing write_vi_sidecar() (atomic temp+rename); apply_permissions modifies only the written file |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-05-01 | Tampering | result.output_path outside media roots before apply_permissions | mitigate | assert_within_media_roots(result.output_path, media_roots) called in the CLI loop before apply_permissions; raises ValueError which is caught by the per-item except block → n_fail++ |
| T-03-05-02 | Information Disclosure | API keys logged via settings repr in error messages | mitigate | SecretStr on both *arr API keys; TrezarrSettings repr/str do not expose secret values; logger never logs `settings` directly |
| T-03-05-03 | Denial of Service | Single bad item (exception) aborts the full batch | mitigate | per-item try/except in the translate loop (D-30); n_fail++ and continue; only the summary at end carries the failure signal |
| T-03-05-04 | Tampering | assert_within_media_roots not called when media_roots is empty | mitigate | When path_mappings is empty, media_roots is empty; guard skipped with an info log. Acceptable: with no path mappings configured, paths are passthrough-identical to API paths, which are from trusted *arr APIs on the same LAN. Document this in code comment. |
| T-03-05-SC | Tampering | npm/pip/cargo installs | mitigate | All packages slopcheck [OK] per 03-RESEARCH.md Package Legitimacy Audit; no new installs in this plan |
</threat_model>
