      """Sonarr *arr API discovery client.

      Design decisions honoured:
        D-22  Discover via pyarr, Sonarr + Radarr both. X-Api-Key auth. Never scan disk to discover.
        D-23  Path mapping applied to every API-returned path before filesystem use.
      """

    MEDIAITEM dataclass: Define `MediaItem` (a shared dataclass exported from sonarr.py):
      @dataclass
      class MediaItem:
          local_path: Path          # resolved local filesystem path to the video file
          series_title: str         # series/movie title for logging
          source_type: str          # "episode" or "movie"
          series_id: int | None = None
          season_number: int | None = None

    FUNCTIONS:

    `build_sonarr_client(settings: "TrezarrSettings") -> Sonarr`:
      - Returns Sonarr(host=settings.sonarr_host, api_key=settings.sonarr_api_key.get_secret_value(), port=settings.sonarr_port, tls=False)
      - .get_secret_value() is called ONLY here — the resolved string is passed directly into Sonarr() and never stored (per SecretStr pattern)
      - tls is hardcoded False for Phase 3 (HTTP to local *arr; HTTPS in Phase 7)

    `discover_sonarr_items(settings: "TrezarrSettings") -> list[MediaItem]`:
      - If not settings.sonarr_enabled: logger.info("Sonarr discovery disabled"); return []
      - client = build_sonarr_client(settings)
      - series_list = client.series.get()  — returns all series (paginated? see A6 assumption)

      - ep_files = client.episode_file.get(series_id=series["id"])
      - For each ep_file: raw_path = ep_file["path"]; local_path = apply_path_mapping(raw_path, settings.path_mappings)
      - Append MediaItem(local_path=local_path, series_title=series["title"], source_type="episode", series_id=series["id"], season_number=ep_file.get("seasonNumber"))
      - Return accumulated list
      - Wrap the whole discovery in try/except httpx.HTTPStatusError and log + re-raise (per 03-PATTERNS.md §"Error handling pattern")

    IMPORTANT correctness guard from 03-RESEARCH.md Pitfall 6:
      For Phase 3's one-shot CLI, sequential per-series episode_file.get() is acceptable but not optimal. Add a comment noting this: "# Phase 7: replace with asyncio.gather + AsyncSonarr for concurrent series iteration". Do NOT add asyncio.gather() in this phase — the CLI uses sync Sonarr client.

    Do NOT scan disk for episode paths. "API for knowledge" (D-22, 03-RESEARCH.md Anti-patterns).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Sonarr/Radarr API response → MediaItem | API-returned paths are untrusted strings; path mapping is applied before they enter MediaItem.local_path |
| TrezarrSettings → pyarr client | SecretStr resolved at client construction only; never stored on client or in MediaItem |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-03-01 | Information Disclosure | sonarr_api_key / radarr_api_key in logs or MediaItem | mitigate | SecretStr; .get_secret_value() called only inside build_sonarr_client() / build_radarr_client(); MediaItem contains no key fields; logger calls never log settings directly |
| T-03-03-02 | Tampering | Arbitrary path injection via *arr API response (movie['path'] injection) | mitigate | apply_path_mapping applied before any filesystem use; assert_within_media_roots() in Plan 03-04 / cli.py validates every resolved write path; Pitfall 2 guard ensures movie directory vs. video file distinction |
| T-03-03-03 | Elevation of Privilege | pyarr connecting to a Sonarr/Radarr running as root with write access | accept | Trezarr only reads from Sonarr/Radarr (GET endpoints); no write calls to the *arr API in Phase 3; discovery is read-only |
| T-03-03-04 | Denial of Service | httpx.HTTPStatusError on 4xx/5xx from Sonarr/Radarr | mitigate | Caught and re-raised at the discovery boundary; CLI batch loop (D-30) logs and quarantines per-item; entire run fails with clear error if discovery itself fails |
</threat_model>
