<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| *arr API response → local filesystem | API-returned paths are treated as untrusted until path-mapped and validated within media roots |
| config env/YAML → settings fields | pydantic-settings validates types; SecretStr prevents accidental logging of API keys |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-02-01 | Tampering | apply_path_mapping → write path | mitigate | assert_within_media_roots() called on every resolved path before any write; raises ValueError on escape (D-29) |
| T-03-02-02 | Information Disclosure | sonarr_api_key / radarr_api_key in logs | mitigate | Both fields are SecretStr; .get_secret_value() called only inside build_sonarr_client() / build_radarr_client() in the arr package — never stored as str on settings |
| T-03-02-03 | Tampering | Path-traversal via crafted path_mappings config (e.g. remote="/", local="/etc") | mitigate | assert_within_media_roots() validates the resolved WRITE target is inside a configured local root; probe_media_roots() verifies roots are readable at startup |
| T-03-02-04 | Denial of Service | probe_media_roots fails closed on unreadable root | accept | By design (D-24) — failing closed is correct; the error message is actionable |
</threat_model>
