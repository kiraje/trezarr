| Boundary | Description |
|----------|-------------|
| Filesystem (media dir) → scan results | Sidecar globs are constrained to media_path.parent — no traversal above the media directory |

| apply_permissions → OS | os.chown/os.chmod on a path that must already be within media roots (caller's responsibility via assert_within_media_roots) |
