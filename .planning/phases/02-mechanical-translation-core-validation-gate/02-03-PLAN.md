## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM response → _parse_numbered_response | LLM output is untrusted; response parsed structurally (numbered-line regex), never evaluated or executed; untrusted content only reaches SubLine.text after passing all 7 gate checks |
| translate_file path arg → filesystem | Path(path).resolve() enforces absolute path at entry; media-root enforcement deferred to Phase 3 |
| quarantine artifact → /config/quarantine/ | Failure artifact records only failing indices + reason, NOT full cue text — source subtitle may be proprietary (V7 error handling + information disclosure control) |
| ledger.json → filesystem | Atomic write (NamedTemporaryFile + os.replace) prevents partial writes; JSONDecodeError fallback prevents ledger corruption from crashing the pipeline |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03-01 | Tampering | LLM response → subtitle text (V5 Input Validation) | mitigate | All LLM-mutated cue text passes through validate_subdoc() (all 7 checks) before write_vi_sidecar is called; gate is the architectural V5 control per ASVS L1 |
| T-02-03-02 | Tampering | Prompt injection via subtitle content | mitigate | extract_sentinels() removes all inline tags before sending text to LLM; numbered-line protocol means model output is parsed structurally (regex) not executed; any injected instructions in cue text are treated as literal strings |
| T-02-03-03 | Information Disclosure | Quarantine artifact leaks subtitle content | mitigate | _write_quarantine() records failing_cue_indices + reason + timestamp + source_path; explicitly does NOT include cue text; grep-checked in acceptance criteria |
