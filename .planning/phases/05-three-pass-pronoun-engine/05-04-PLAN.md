<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Subtitle dialogue → Pass-1 LLM prompt | Source cue texts are included in the prompt; a crafted subtitle line could attempt prompt injection |
| arr_metadata snapshot → Pass-1 LLM prompt | title/genres/overview/year fields included in prompt; oversized overview could bloat context |
| LLM output → BibleAnalysis Pydantic parse | Structured JSON from LLM is validated by Pydantic before any store write |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-04-01 | Tampering | Prompt injection via subtitle text (e.g. dialogue line "IGNORE PREVIOUS INSTRUCTIONS") | mitigate | Subtitle cue texts are included as labeled data under the [DIALOGUE SAMPLE] section heading, not as instructions. The sentinel extract_sentinels() pattern (D-12) is applied in Pass 3 engine; analyze_file includes raw cue texts as numbered items. The LLM treats the full dialogue block as data to analyze, not instructions to follow. Log any suspiciously long individual cue text (> 500 chars). |
| T-05-04-02 | Tampering | Malicious arr_metadata snapshot injected via oversized overview field | mitigate | Already mitigated by MAX_ARR_METADATA_BYTES cap in store.py (RESEARCH.md § Security Domain). analyze_file must include only known arr_metadata fields (title, genres, overview, year, network) — never raw metadata dump. |
| T-05-04-03 | Tampering | BibleAnalysis validation bypass (Tier-2 attacker-controlled JSON) | mitigate | Pydantic model_validate_json() enforces field types. Unknown extra fields are ignored by default (model_config should use extra="ignore"). Malformed JSON raises ValidationError → BibleAnalysisError → quarantine (controlled failure). |
| T-05-04-04 | Tampering | Address Map poisoning via Pass-1 inference with wrong self_term/address_term | mitigate | upsert_address_pair respects locked_fields (D-34). Phase-5 inferences never set locks. Human can correct via Phase-8 UI. Residual risk: LOW. |
| T-05-04-SC | Tampering | npm/pip/cargo installs | accept | No new packages. Residual risk: LOW. |

Residual risk after mitigations: LOW. The primary injection surface (subtitle content) is data-labeled in the prompt structure. The structured-output path validates before persistence.
</threat_model>
