<objective>
Deliver the character + term + merge slice that puts the consistency engine substrate in place. Build the pure-Python lock-precedence policy (`trezarr/bible/merge.py`) and extend `trezarr/bible/store.py` with `get_character`/`get_term`/`upsert_character`/`upsert_term`/`merge_inferred`. The crown jewel is `merge_inferred`: it enforces `human lock > prior value > new inference` (D-34, success criterion 4), it writes the current-row UPDATE and the bible_event row(s) in ONE transaction (D-32), and it is exhaustively tested for lock survival, no-op detection, atomicity-on-failure, and carry-forward semantics (BIBLE-06).

Purpose: This is the policy substrate Phase 5's LLM Pass-1 will call when it has new character/term inferences from a translated episode. The merge contract guarantees that locked corrections never get overwritten by silent inference drift, that unchanged inferences produce zero audit churn, and that the audit trail (bible_event) cannot become inconsistent with the current state. Without these guarantees, the entire Series-Bible-as-consistency-engine value proposition fails.

Output: Characters and Term Dictionary rows persist + survive cross-episode reads unchanged (BIBLE-06 carry-forward); merge_inferred enforces lock precedence + atomic provenance; bible_event log is the auditable record of every Bible mutation. Phase 5 can now call `merge_inferred(session_factory, character_dto, {"role": "spy"}, episode_key="S02E03", source="inference")` and trust the lock+atomicity invariants without re-implementing them.
</objective>

    ```
    def get_locked_fields(entity_dto: Any) -> frozenset[str]:
        """Read locked_fields off any DTO/object that carries the convention.

        Defensive — returns frozenset() if the attribute is missing. Phase 8 may
        swap entity_dto.locked_fields for a database-side lookup; the only
        contract this function exposes is "give me the set of locked field names
        for this entity."
        """
        return frozenset(getattr(entity_dto, "locked_fields", []) or [])
    ```

    ```
    def compute_field_changes(
        entity_dto: Any,
        inferred: dict[str, Any],
        locked: frozenset[str],
    ) -> list[tuple[str, Any, Any]]:
        """Return [(field, old, new), ...] for fields that should actually change.

        Skips fields in `locked` (human lock wins — D-34 / success criterion 4).
        Skips no-op fields where inferred == current (D-32 / BIBLE-06 carry-forward).
        Treats a missing attribute on entity_dto as old_value=None.

        Pure function — no DB, no side effects. Easy to unit test exhaustively.
        """
        changes: list[tuple[str, Any, Any]] = []
        for field, new_val in inferred.items():
            if field in locked:
                continue
            old_val = getattr(entity_dto, field, None)
            if old_val == new_val:
                continue
            changes.append((field, old_val, new_val))
        return changes
    ```
