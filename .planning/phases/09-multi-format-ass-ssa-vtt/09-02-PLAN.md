<objective>
Wave 1 shared foundation: three targeted extensions that every format-specific slice depends on. The timecode extension is the fail-closed blocker (tc_to_ms returns 0 for ASS/VTT today → GateError on every file). The envelope field is the carrier that lets write_ass/write_vtt recover the format structure from a translated SubDoc. The sentinel extension protects ASS hard breaks before they reach the LLM.

Purpose: These three changes are the smallest possible set that unblocks the ASS and VTT codec plans. They touch minimal lines in production code, have no behavioral effect on the SRT pipeline, and are verified by the Wave 0 test stubs.

Output: model.py gains one field; _timecode.py gains three regex patterns and a cascaded match chain; sentinel.py gains one regex arm. No new files.
</objective>
