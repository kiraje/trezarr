<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Source subtitle path suffix → dispatch | Suffix used for codec routing; no shell execution; pure dict lookup |
| Sidecar path derivation | derive_vi_sidecar_path output used for file writes; path-traversal guard upstream in assert_within_media_roots |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-05-A | Tampering | dispatch.py suffix routing | mitigate | Allowlist-based dispatch: only .srt/.ass/.ssa/.vtt are in _READERS/_WRITERS. Unknown suffix raises ValueError before any file I/O. No arbitrary code execution from suffix string. |
| T-09-05-B | Tampering | derive_vi_sidecar_path extension propagation | mitigate | Output path uses media_path.suffix.lower() — only the suffix characters, no user-controlled string interpolation. Path stays within media_path.parent (same directory). paths.assert_within_media_roots() is called by the engine upstream before this function output is used. |
| T-09-05-C | Tampering | envelope object passed through pipeline | accept | SubDoc.envelope is set only by trusted codec code and read only by trusted codec code. The pipeline (engine, batching, gate) never reads it. No untrusted data flows into the envelope type or its fields. |
| T-09-05-D | Elevation of Privilege | AUTO-04 self-output exclusion regression | mitigate | tests/discover/test_gap_format.py explicitly tests .vi.ass and .vi.vtt exclusion. derive_vi_sidecar_path is the single canonical source for vi-path derivation (RESEARCH A5) — fixing it propagates to all consumers. |
</threat_model>
