    minimal.srt: LF line endings, comma timecodes, 3-digit ms. Single cue:
      index "1", timecode "00:00:01,000 --> 00:00:03,500", text "Hello world".
      End with a single trailing blank line (LF+LF after last text line).

    crlf_indices.srt: CRLF (\r\n) line endings throughout. Non-sequential indices starting at 5.
      Two cues: index "5" and index "10". Comma timecodes, 3-digit ms.
      Text lines may include a line with a two-line cue text to exercise multi-line text join.
      Trailing blank line uses CRLF.

    period_timecodes.srt: LF line endings. Period separator in timecodes ("00:00:01.000 --> 00:00:02.500"),
      2-digit milliseconds ("00:00:05.50 --> 00:00:07.00"). Two cues with non-sequential indices ("3", "7").
      These exact timecodes must be preserved verbatim (neither normalized to comma nor padded to 3 digits).

    utf8bom.srt: UTF-8 BOM (bytes EF BB BF) at the very start of the file, then normal SRT.
      LF line endings. Single cue with Vietnamese text in the cue text field (e.g. "Xin chào").
      The BOM must be the first 3 bytes of the file.

    inline_bold.srt: LF line endings, comma timecodes. Three cues:
      Cue 1 text: "<b>Bold line</b>"
      Cue 2 text: "<font color=\"#ffffff\">Colored</font>"
      Cue 3 text: "{\\an8}Positioned text"
      All tags must be preserved byte-identical through round-trip.

    malformed_index.srt: LF line endings. Contains one well-formed cue (index "1") followed by one
      malformed block whose "index" line is "abc" (non-integer). The malformed block should have a
      valid-looking timecode line but a non-integer index. The well-formed cue must round-trip;
      the behavior for the malformed cue is defined by D-10 (preserved-and-flagged, never crash).
      Include just the two blocks — minimal enough to test the preserve-and-flag path.
