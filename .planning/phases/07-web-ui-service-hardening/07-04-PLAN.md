## Phase Goal

**As an** operator, **I want to** configure Sonarr/Radarr/Bazarr connections and the LLM endpoint through a web UI — with connection tests and without my API keys ever being returned to the browser — **so that** I can safely set up the service without reading config files directly.

<objective>
Implement the config read/write service (D-70) and connection-test endpoints (D-71). The config writer masks secrets on read, accepts updates via PUT, and writes back to /config/config.yaml with the write-only secret discipline. Connection-test endpoints ping *arr system/status and the LLM endpoint; they never include the API key in the response. Wire both router sets into app.py.

Purpose: Closes SVC-02 — the operator can configure all connections from the UI.
Output: trezarr/web/config_writer.py + settings and test_connection route modules, wired into app.py.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → GET /api/settings | Response must never contain raw SecretStr values (HIGH finding if violated) |
| Browser → PUT /api/settings | Writes to /config/config.yaml; path is CONFIG_PATH constant (not from request body) |
| Browser → POST /api/test/* | Receives api_key in request body; must never echo it in response or logs |
| YAML write path | CONFIG_PATH is a constant from config.py; not derived from user input — no path traversal possible |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-04-01 | Information Disclosure | GET /api/settings returns SecretStr value (HIGH) | mitigate | settings_to_display_dict replaces all SECRET_FIELDS with {is_set, value: SENTINEL}; test_secret_never_in_response verifies no raw value escapes. This is the single highest-priority threat in Phase 7. |
| T-07-04-02 | Information Disclosure | POST /api/test/* error response contains api_key (HIGH) | mitigate | Error message uses str(exc)[:200] which is the pyarr exception message (not the key); _normalize_arr_host strips credentials from host display; test_secret_not_in_connection_error verifies this |
| T-07-04-03 | Tampering | PUT /api/settings writes arbitrary path | accept | CONFIG_PATH is a process-constant (env > hardcoded default "/config/config.yaml"); request body is a patch dict, not a file path; no traversal vector |
| T-07-04-04 | Tampering | yaml.safe_dump injection via crafted field values | mitigate | yaml.safe_dump escapes special characters; only string/int/bool primitives from Pydantic-validated body reach the YAML writer |
| T-07-04-05 | Denial of Service | Unbounded /api/test/* calls against external services | accept | Trusted-LAN single-user (D-78); connection tests are user-initiated, not automated; no rate limiting needed for v1 |
| T-07-04-SC | Tampering | No new packages installed | accept | n/a |
</threat_model>
