## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Sonarr/Radarr/Bazarr → POST /webhook | Inbound HTTP from *arr stack; unauthenticated (D-78 trusted-LAN); payload content not trusted for file paths |
| webhook payload → poll_and_enqueue | series_id hint extracted from payload but used only to narrow a scan; never used as a direct file path |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-03-01 | Denial of Service | POST /webhook unauthenticated flood | mitigate | Webhook handler creates exactly one asyncio.Task per call; task deduplicates via enqueue_job guard; a flood of webhooks creates at most one queued job per unique source_path |
| T-07-03-02 | Spoofing | Webhook payload series.id used as hint | accept | series_id_hint is only a filter hint; all eligible items are still discovered via pyarr (authoritative source); a spoofed ID causes a wider/no scan, not a wrong write |
| T-07-03-03 | Tampering | translate_file called inside webhook handler | mitigate | Handler explicitly uses asyncio.create_task; never awaits poll_and_enqueue in request scope (Pitfall D enforced in code review / test_webhook_returns_200_fast) |
| T-07-03-04 | Spoofing | APScheduler started at module scope using wrong event loop | mitigate | scheduler.start() called inside lifespan function after uvicorn loop is running (Pitfall B avoided; verified by test_lifespan_startup_shutdown) |
| T-07-03-SC | Tampering | No new packages installed in this plan | accept | n/a |
</threat_model>
