## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → GET /api/queue, /api/jobs | Read-only data access; no auth (D-78); returns only job metadata, not file contents |
| Browser → POST /api/jobs/{id}/retry | Modifies job state; only allows retry of failed/quarantined (409 if wrong state) |
| SPA origin → FastAPI | Same origin (served by the same process on port 6868); no CORS complexity |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-05-01 | Information Disclosure | GET /api/jobs returns error_reason (may contain paths) | accept | error_reason contains translation failure messages from the pipeline; no secrets; Trusted-LAN (D-78). Truncate at 500 chars as a precaution. |
| T-07-05-02 | Denial of Service | GET /api/jobs returns unbounded history rows | mitigate | LIMIT 200 on the query per RESEARCH.md §V13 API; prevents OOM from large history tables |
| T-07-05-03 | Denial of Service | GET /api/jobs/{id}/logs returns unbounded log rows | mitigate | LIMIT 1000 log rows per job (per RESEARCH.md §V13 log retention guidance); job_log rows older than N days can be pruned in a future maintenance job |
| T-07-05-04 | Tampering | POST /api/jobs/{id}/retry on non-retriable job | mitigate | HTTPException(409) if status NOT IN ('failed','quarantined') — running or queued jobs cannot be double-retried |
| T-07-05-05 | Tampering | React SPA injects arbitrary HTML via log messages | mitigate | LogViewer renders log lines as textContent (not innerHTML) — no XSS from log content |
| T-07-05-SC | Tampering | npm install (react, vite, tailwindcss, lucide-react, react-router-dom, typescript) | mitigate | All packages in RESEARCH.md Package Legitimacy Audit as Approved; canonical ecosystem packages with multi-year history |
</threat_model>
