## Phase Goal

**As an** operator, **I want to** run `trezarr serve` and have the service start a crash-safe long-running daemon that resumes in-progress work on startup and serializes per-series translation, **so that** automated Vietnamese subtitle translation can run unattended with restart safety.

<objective>
Install new Python dependencies, extend TrezarrSettings with Phase-7 fields (D-76/D-77), add the Job/JobLog persistence layer + Alembic 0002 migration (D-69), refactor cli.py to extract the shared process_one_item callable (D-62), create the FastAPI app with CR-01-correct lifespan (D-61), implement the queue worker with per-series asyncio.Lock serialization + two-arm crash-resume reconciliation (D-67/D-68), and wire the `trezarr serve` CLI subcommand (D-62).

This is the service spine: no web UI, no monitoring endpoints yet — but `trezarr serve` starts and the worker picks up crashed items on restart from both the job queue and the processed_file ledger.

Purpose: The first end-to-end slice that makes the service a real daemon rather than a one-shot CLI.
Output: A runnable `trezarr serve` command backed by a crash-safe job queue, and a shared per-item callable reused by both the CLI loop and the daemon worker.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI input → trezarr serve | Attacker can pass arbitrary --config path; validated by TrezarrSettings/pydantic-settings parsing |
| job.source_path → worker | source_path stored in DB; worker must not trust it for path traversal — assert_within_media_roots applies before any write (inside process_one_item) |
| enqueue_job | Accepts trigger from scheduler/webhook; trigger field constrained by CheckConstraint to known values |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-02-01 | Tampering | worker._execute_job source_path | mitigate | assert_within_media_roots(result.output_path, media_roots) before apply_permissions — existing guard reused unchanged inside process_one_item (INTG-03/04) |
| T-07-02-02 | Denial of Service | asyncio.Queue unbounded growth | mitigate | enqueue_job dedup guard: skip if source_path already queued/running; poll and webhook both hit this guard (D-66) |
| T-07-02-03 | Spoofing | engine created at module scope | mitigate | Engine created inside lifespan function (never at module scope) — CR-01 invariant enforced; Pitfall A avoided |
| T-07-02-04 | Tampering | job trigger field accepts arbitrary strings | mitigate | CheckConstraint ck_job_trigger limits values to known enum; any other value raises IntegrityError |
| T-07-02-SC | Tampering | uv add new packages (fastapi, uvicorn, apscheduler, watchfiles, httpx) | mitigate | All packages appear in 07-RESEARCH.md Package Legitimacy Audit as Approved; CLAUDE.md prescribes these exact packages |
