## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Pass-3 translated_doc → Pass-4 reviewer LLM | Translated Vietnamese text (with sentinels) crosses to the LLM reviewer; adversarial reviewer could "correct" to malicious content |
| LLM reviewer response → corrected_lines splice | parse_numbered_response output replaces SubLine text; integrity check is the guard |
| corrected translated_doc → validate_subdoc | validate_subdoc is the structural arbiter; it runs unconditionally after Step 8.5 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-03-01 | Tampering | Prompt injection via self-review "correction" to malicious text | mitigate | Review prompt instructs "return verbatim unless SPECIFIC Bible violation" (D-58). Sentinel protection (`extract_sentinels`/`reinsert_sentinels`) preserves `<<T...>>` inline-tag tokens — reviewer cannot corrupt them. `validate_subdoc` 7-check gate catches structural corruption (cue-count mismatch, invalid format) before any write. |
| T-06-03-02 | Denial of Service | Reviewer always fails → pre-review output used → fine, not a DoS | accept | D-59 best-effort semantics: reviewer failure → keep pre-review → validate_subdoc runs → either passes (file written) or fails (file quarantined as normal). No new DoS vector introduced. |
| T-06-03-03 | Tampering | Pass-4 TaskGroup exception propagation quarantines a passing translation (Pitfall 2) | mitigate | `_review_batch` never raises (full `except Exception → return None`). TaskGroup itself wrapped in bare `except Exception → review_results = [None]*N`. No `except*` block in the Step 8.5 TaskGroup. No `_write_quarantine` reachable from Pass-4 paths (D-59). |
| T-06-03-04 | Tampering | Sentinel integrity failure silently corrupts inline tags | mitigate | `reinsert_sentinels` returns `(text, integrity_ok)`. If `integrity_ok=False`, `_review_batch` returns `None` for that batch → pre-review lines kept. Sentinel corruption never reaches `validate_subdoc`. |
| T-06-03-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed in Wave 2. All libraries already in pyproject.toml. |
</threat_model>
