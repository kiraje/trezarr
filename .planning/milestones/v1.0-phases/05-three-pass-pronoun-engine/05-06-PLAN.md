## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-06-01 | Tampering | Pronoun hint injection via LLM-controlled self_term/address_term in Pass-3 prompt | mitigate | Pronoun hints come from the Address Map (upsert_address_pair with ORM parameterized writes), not directly from LLM text output. LLM only sets these values via BibleAnalysis Pydantic validation and upsert_address_pair lock-precedence (D-34). A crafted subtitle cannot bypass the merge contract. |
| T-05-06-02 | Tampering | BibleAnalysisError quarantine bypass (catching openai.APIError as BibleAnalysisError) | mitigate | Only BibleAnalysisError (defined in analyze.py, not a subclass of openai.APIError) is caught in the quarantine block (Pitfall B). openai.APIError propagates unhandled, leaving the file in in_progress state for retry. |
| T-05-06-03 | Elevation of Privilege | cli.py session_factory passed to translate_file enables unexpected DB writes | mitigate | session_factory is scoped to the _run_once function and is the same factory used by all Phase-4 Bible operations. No new DB permissions granted. All writes go through store.py's ORM functions (D-39). |
| T-05-06-04 | Denial of Service | Pass 1+2+3 LLM calls tripling per-file API usage; DoS via rate limits | accept | asyncio.Semaphore in LLMClient bounds concurrent calls (D-06). Tenacity retries only at pipeline step level. SDK max_retries handles transient errors. No new concurrency gate added (Pitfall A). Operator is responsible for their endpoint capacity. Residual risk: LOW. |
| T-05-06-SC | Tampering | npm/pip/cargo installs | accept | No new packages. Residual risk: LOW. |

Residual risk after mitigations: LOW. The primary security controls (lock precedence, ORM parameterization, BibleAnalysisError specificity, validation gate) are all upstream of the wiring in this plan.
