    Create Dockerfile with two stages:

    Stage 1 — node-builder:
    FROM node:20-slim AS node-builder. WORKDIR /app. COPY frontend/package.json frontend/package-lock.json (or package.json only if no lockfile) ./frontend/. RUN cd frontend && npm ci --prefer-offline. COPY frontend/ ./frontend/. RUN cd frontend && npm run build. Output: /app/trezarr/web/static/ (matches vite.config.ts outDir).

    Stage 2 — Python runtime:
    FROM python:3.12-slim. Install uv: RUN pip install uv --no-cache-dir. WORKDIR /app. COPY pyproject.toml uv.lock* ./. RUN uv sync --frozen --no-dev --no-editable. COPY trezarr/ ./trezarr/. COPY alembic/ ./alembic/. COPY alembic.ini ./. COPY --from=node-builder /app/trezarr/web/static ./trezarr/web/static.

    PUID/PGID drop-privilege (python:3.12-slim + entrypoint script, the mvp approach per RESEARCH.md Open Question 1):
    Create an ENTRYPOINT script that:
    1. Reads PUID (default 1000) and PGID (default 1000) env vars
    2. Creates group (if PGID != existing) and user (if PUID != existing)
    3. chown -R $PUID:$PGID /config
    4. exec gosu $PUID:$PGID "$@" (use gosu for clean privilege drop — install via RUN apt-get install -y gosu in the Python stage)

    VOLUME ["/config"]. EXPOSE 6868. ENV TREZARR_CONFIG_PATH=/config/config.yaml. ENTRYPOINT ["/entrypoint.sh"]. CMD ["trezarr", "serve"].

    HEALTHCHECK: HEALTHCHECK --interval=30s --timeout=5s --start-period=30s CMD curl -f http://localhost:6868/api/health || exit 1. Install curl: RUN apt-get update && apt-get install -y --no-install-recommends curl gosu && rm -rf /var/lib/apt/lists/*.

    Create .dockerignore:
    Exclude: frontend/node_modules/, frontend/dist/, .planning/, .claude/, .codegraph/, tests/, __pycache__, *.pyc, .git/, .gitignore, *.md (except README.md if it exists), .env, .gsd_*.

    Include a comment block at the top: "# Media paths MUST match the paths Sonarr/Radarr/Bazarr see in their containers. # If Sonarr mounts /media, Trezarr must also mount /media. # See CLAUDE.md §Docker Packaging."

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Container runtime → host filesystem | PUID/PGID drop-privilege ensures sidecar files written with correct host ownership; gosu handles clean privilege drop |
| Docker HEALTHCHECK → FastAPI | curl to localhost:6868/api/health; internal-only, never exposed as a public endpoint |
| /config volume | Holds SQLite DB, config.yaml (may contain connection strings); volume must be private to the operator |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-06-01 | Elevation of Privilege | Container running as root (PUID/PGID not set) | mitigate | ENTRYPOINT script always uses gosu to drop to PUID:PGID before exec; default PUID/PGID=1000 ensures non-root operation even without explicit env vars |
| T-07-06-02 | Information Disclosure | API keys in docker-compose environment block | mitigate | docker-compose.example.yml uses ${TREZARR_*_API_KEY} env var references, not literal values; operator provides them at runtime |
| T-07-06-03 | Tampering | Media volumes not at same paths as *arr | accept | Documented in docker-compose.example.yml comment block; assert_media_roots_configured enforces at startup |
| T-07-06-04 | Denial of Service | Docker build pulls unverified npm packages | mitigate | frontend/package.json uses only packages from RESEARCH.md legitimacy audit (Approved); `npm ci --prefer-offline` uses the lockfile for reproducibility |
| T-07-06-05 | Information Disclosure | config.yaml.example shows bare api_key fields | mitigate | Security note in config.yaml.example instructs use of env vars; bazarr_api_key example shows empty string with env var guidance |
| T-07-06-SC | Tampering | gosu (apt package) — package legitimacy | mitigate | gosu is a well-known Docker privilege-drop utility maintained by the Docker team (github.com/tianon/gosu); same as used by official Postgres/Redis images |
</threat_model>
