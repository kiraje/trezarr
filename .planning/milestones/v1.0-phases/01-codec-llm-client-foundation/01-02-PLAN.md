    Create trezarr/subtitles/srt.py implementing read_srt and write_srt per research Pattern 1.

    Imports: re, from pathlib import Path, from .model import SubLine SubDoc, from .encoding import detect_encoding.
    Do NOT import pysubs2 — the custom parser is the sole SRT implementation per D-08 research finding.

    read_srt(path: str | Path) -> SubDoc:
      1. raw_bytes = open(path, "rb").read()
      2. encoding = detect_encoding(raw_bytes)
      3. text = raw_bytes.decode(encoding)
      4. le: str = "\r\n" if "\r\n" in text else "\n"
      5. trailing = text.rstrip(" \t").endswith(le + le) — detect trailing blank line in original
      6. blocks = re.split(r"\r?\n\r?\n", text.strip())  — split on blank lines (handles both LF and CRLF)
      7. For each block: strip, skip if empty. splitlines() to get block_lines.
         - If len(block_lines) < 2: malformed — log warning (D-10), skip block
         - index = block_lines[0].strip()
         - tc_match = re.match(r"(\d{2}:\d{2}:\d{2}[,\.]\d+)\s*-->\s*(\d{2}:\d{2}:\d{2}[,\.]\d+)", block_lines[1])
         - if not tc_match or not re.match(r"^\d+$", index.strip()): malformed — log warning, skip block (D-10)
         - text_lines = le.join(block_lines[2:]) — rejoin multi-line cue text with detected line ending
         - Append SubLine(index=index, start_tc=tc_match.group(1), end_tc=tc_match.group(2), text=text_lines)
      8. return SubDoc(lines=lines, encoding=encoding, line_ending=le, trailing_newline=trailing)

    The ReDoS mitigation: the timecode regex `[,\.]` and `\d+` have no catastrophic backtracking because
    they are applied only to single lines (already split). The blank-line split `\r?\n\r?\n` is linear.
    Both regexes are safe (no nested quantifiers, no ambiguous alternation).

    write_srt(doc: SubDoc, path: str | Path) -> None:
      le = doc.line_ending
      parts = [f"{sl.index}{le}{sl.start_tc} --> {sl.end_tc}{le}{sl.text}" for sl in doc.lines]
      result = (le + le).join(parts)
      if doc.trailing_newline:
          result += le + le
      open(path, "wb").write(result.encode(doc.encoding))

    The warning for malformed cues (D-10) uses import warnings; warnings.warn(..., UserWarning).
    Never raise on malformed input — only warn and skip that cue.

| Boundary | Description |
|----------|-------------|

| codec → LLM pipeline (Phase 2+) | SubLine.text is the only field passed to the LLM; index/start_tc/end_tc are immutable |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-02-01 | Tampering | trezarr/subtitles/srt.py — SRT parser | mitigate | Custom regex parser; malformed cues preserved-and-flagged (D-10), never eval()/exec(); no shell execution. ReDoS mitigated by split-on-blank-lines-first before applying timecode regex (linear complexity). |
| T-01-02-02 | DoS | trezarr/subtitles/srt.py — timecode regex | mitigate | Timecode regex `[,\.]` + `\d+` applied only to single lines already split from the block; no nested quantifiers; no catastrophic backtracking possible. |
