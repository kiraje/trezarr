## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → FastAPI bible router | User-supplied entity_type, field, new_value, lock flag cross the HTTP boundary; all must be validated before touching the DB |
| bible router → store functions | Router passes validated params to store writers; store also validates (defence in depth) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Tampering | PATCH endpoints — arbitrary field name injection via `body["field"]` | mitigate | Validate `field` against `MERGEABLE_FIELDS.get(entity_type, frozenset())` at route entry; raise HTTP 422 before any store call; MERGEABLE_FIELDS whitelist at store.py:259-264 is the canonical allowlist |
| T-08-02 | Denial of Service | GET /api/series — unbounded series list | mitigate | load_all_series uses `select(Series).order_by(Series.id).limit(500)` — a LIMIT 500 read guard; returning 500+ series in a single response would otherwise exhaust memory |
| T-08-03 | Denial of Service | GET /api/.../history — unbounded event query | mitigate | load_field_history enforces `LIMIT 100` (default); route does not accept a user-supplied limit parameter |
| T-08-04 | Tampering | entity_type in history URL path — arbitrary table scan via entity_type injection | mitigate | `VALID_ENTITY_TYPES = {"character", "term_dictionary", "series", "address_map"}` allowlist check at route entry; HTTP 422 on unknown value |
| T-08-05 | Tampering | address_map_id / character_id path params — integer injection | accept | FastAPI path params typed as `int` reject non-integer values automatically; SQLAlchemy parameterized queries prevent SQL injection |
| T-08-06 | Tampering | Locking AddressMap pair with empty term bypasses reconcile.py:275 non-None guard | mitigate | HTTP 422 at route layer when lock=True and either term is empty/whitespace (D-87); store writer also enforces as ValueError; two-layer defence |
| T-08-07 | Elevation of Privilege | Registering bible_router after StaticFiles — all /api/series calls silently return index.html 200 | mitigate | include_router(bible_router, prefix="/api") placed BEFORE app.mount("/", StaticFiles(...)) in app.py (Pitfall E); contract test in test_bible_api.py confirms API returns JSON not HTML |
| T-08-08 | Tampering | DELETE handlers doing inline session.get/session.delete — would import SQLAlchemy models (D-39) | mitigate | DELETE handlers call delete_address_pair / delete_term store functions via deferred import; no SQLAlchemy model in route module; enforced by test_bible_route_does_not_import_sqla |
| T-08-SC | Tampering | npm/pip/cargo installs | accept | No new packages in this phase |
</threat_model>
