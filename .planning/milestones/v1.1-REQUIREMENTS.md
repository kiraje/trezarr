## v1.1 Requirements (17 total — all shipped)

### UI — Foundation & Theme

- [x] **UI-01**: shadcn/ui + jolly-ui component foundation installed on Tailwind v3 (`cn()` util, `@/` path alias, `components.json`, base primitives); the SPA build stays green throughout — Phase 11
- [x] **UI-02**: A purple CSS-variable theme (dark mode default) replaces the legacy custom hex tokens across every page — Phase 11

### NAV — Navigation Shell

- [x] **NAV-01**: Full-height sidebar shell with brand (logo glyph + "TREZARR" pill); the active section is marked with a left purple accent bar — Phase 12
- [x] **NAV-02**: Navigation exposes Series / Movies / Queue / History / Bible / Settings; `/library` splits into `/series` and `/movies`; `/` redirects to `/series` — Phase 12
- [x] **NAV-03**: Nav rows show a right-side count badge of items needing a Vietnamese subtitle (auto-hidden at zero) and a "LIVE" badge when the backing *arr service is connected — Phase 14

### LIB — Library Browsing

- [x] **LIB-01**: Browse all Sonarr series on a Series list page — Phase 14
- [x] **LIB-02**: Browse all Radarr movies on a Movies list page showing source-subtitle and Vietnamese-subtitle status — Phase 14
- [x] **LIB-03**: Open a series and see its episodes grouped by season in collapsible sections (latest season auto-expanded) — Phase 14
- [x] **LIB-04**: Each episode row shows an Audio-language badge and subtitle-language badges (`CODE2` uppercase, `:HI`/`:Forced` markers; amber = source / purple = Vietnamese; non-color shape + `aria-label` distinction) — Phase 14
- [x] **LIB-05**: Trigger translation for a single episode or an entire season from the Series detail view (enqueues via `POST /api/translate`) — Phase 14
- [x] **LIB-06**: Search, filter by subtitle status, and sort the Series and Movies lists — Phase 14
- [x] **LIB-07**: Series and Movies list items show a Vietnamese-subtitle translation-progress indicator (translated / total) — Phase 14

### API — Backend Episode Data

- [x] **API-01**: `GET /api/library/series/{id}/episodes` returns Sonarr episode records grouped by season, each carrying `audio_languages` + `subtitles[]` (Bazarr inventory incl. `hi`/`forced`) + Trezarr status; Bazarr failures degrade fail-soft (HTTP 200, no subtitle badges) — Phase 13
- [x] **API-02**: The library Series + Movies list endpoints expose per-item `translated_count` / `total_count` for the progress indicators and nav badges — Phase 13

### RSK — Reskin & Delivery

- [x] **RSK-01**: Queue, History, Settings, Bible List, and JobLogs pages reskinned to shadcn with loading / empty / error states — Phase 15
- [x] **RSK-02**: Bible Editor reskinned in-place (primitives swapped; locking semantics and behavior unchanged; existing tests stay green) — Phase 15
- [x] **RSK-03**: Multi-stage Docker image rebuilt and the new dashboard live-smoke-tested on :6868 (SPA deep-link fallback intact) — Phase 16
