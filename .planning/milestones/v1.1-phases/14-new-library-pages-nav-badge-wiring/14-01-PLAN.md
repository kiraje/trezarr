<task type="auto">
  <name>Task 2: Create LibraryContext.tsx — shared GET /api/library state</name>
  <files>frontend/src/contexts/LibraryContext.tsx</files>
  <action>
    Create the directory frontend/src/contexts/ if it does not exist, then create
    frontend/src/contexts/LibraryContext.tsx.

    The context allows Series.tsx and Movies.tsx to populate library data after their fetch, and
    allows app-sidebar.tsx to read the counts + LIVE badge state without making its own fetch.

    Pattern: raw React context with useState. No library. No polling. Zero runtime overhead when
    the context data is null.

    CONTEXT VALUE type (LibraryContextValue):
      libraryData: LibraryResponse | null;
      setLibraryData: (data: LibraryResponse) => void;

    Where LibraryResponse is the NEW one from client.ts (with SeriesItem/MovieItem shapes).

    PROVIDER (LibraryProvider):
      - useState<LibraryResponse | null>(null)
      - provides { libraryData, setLibraryData } to children
      - export default + named export

    HOOK (useLibraryContext):
      - useContext(LibraryContext) — throws if context is null with an Error("useLibraryContext
        must be used inside LibraryProvider") so missing providers are caught early
      - export

    DERIVED HELPERS (pure, exported, used by app-sidebar.tsx):

    getSeriesLiveBadge(data: LibraryResponse | null): boolean
      Returns true when Sonarr is live per D-10 rule:
      data !== null && (data.series.length > 0 || !data.errors.some(e => e.source === "sonarr"))

    getMoviesLiveBadge(data: LibraryResponse | null): boolean
      Returns true when Radarr is live per D-10 rule:
      data !== null && (data.movies.length > 0 || !data.errors.some(e => e.source === "radarr"))

    getSeriesNeedsViCount(data: LibraryResponse | null): number
      Returns data?.series.filter(s => s.translated_count < s.total_count).length ?? 0

    getMoviesNeedsViCount(data: LibraryResponse | null): number
      Returns data?.movies.filter(m => m.translated_count < m.total_count).length ?? 0

    WIRE the LibraryProvider into App.tsx: import LibraryProvider from "./contexts/LibraryContext"
    and wrap the <BrowserRouter> (or wrap the <Routes> — either works; wrap BrowserRouter so the
    provider is above the router and sidebar can consume it). Read App.tsx first to find the exact
    wrapping point. Do NOT modify any routes in this task — just add the provider wrapper.

    File header docstring: cite 14-CONTEXT.md D-09 and D-10 for the derivation rules. Note the
    documented approximation: counts use translated_count < total_count (not per-episode source-sub
    check) — this is intentional and documented.

    Strict TS: import React (or use React namespace) only as needed. Use React.createContext,
    React.useState, React.useContext. All exports must be used (noUnusedLocals — the helpers are
    exported so the sidebar file can import them).
