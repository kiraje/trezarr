# Milestone v1.0: MVP — Automated Vietnamese Subtitle Translator

**Status:** ✅ SHIPPED 2026-06-03
**Phases:** 1-10
**Total Plans:** 44

## Overview

Trezarr v1.0 is built leaves-first, novel-logic-last. We start by proving the mechanical
file-in → file-out path (parse a real SRT, hit the user's LLM endpoint, validate, write a
sidecar) with the blind-trust validation gate built in from day one. We then wire in *arr
discovery to get one real episode translated end-to-end — de-risking path-mapping and
permissions, the ecosystem's biggest friction — before investing in the moat. With a working
slice, we build the persistent Series Bible store, then the three-pass pronoun engine (the
differentiator), then relationship-evolution and self-review on top of a proven consistency
core. Finally we add the operator surfaces (web UI, hardened service, editable Bible) and the
orthogonal depth (ASS/SSA + VTT formats, relational-fidelity source selection). Each phase
delivers a coherent, verifiable capability; every v1 requirement lands in exactly one phase.

## Milestone Summary

**Key Decisions** (see PROJECT.md Key Decisions for outcomes):

- Leaves-first ordering — codec + LLM client (Phase 1) before any novel logic; the validation gate is foundational (Phase 2), not polish.
- First vertical slice (Phase 3) de-risks *arr path-mapping/permissions before investing in the Series Bible moat.
- Address Map (BIBLE-03) and attribution (PRON) ship together in Phase 5 — co-dependent; neither delivers value alone.
- Per-episode pronoun consistency is a deterministic reconciliation property (one `(self_term, address_term)` per ordered pair per episode, reciprocal-coherent via a Vietnamese kinship table), not an LLM gamble.
- Persistent, editable per-series Series Bible (SQLite + lock precedence `human lock > prior value > new inference`) is the consistency core; the editable+lockable valve (Phase 8) is the only human touchpoint.
- Source-agnostic input ranked by relational fidelity, biased so the native original-language source always wins; per-series overrides for source/register/model.
- Single multi-stage Docker image, `/config` volume, port 6868, PUID/PGID via gosu; FastAPI lifespan owns the engine + APScheduler poll + `/webhook` + per-series-serialized worker.
