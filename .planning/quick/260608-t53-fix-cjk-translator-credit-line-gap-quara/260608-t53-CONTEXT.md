# Quick Task 260608-t53: Fix CJK translator-credit-line gap quarantining whole files - Context

**Gathered:** 2026-06-08
**Status:** Ready for planning

<domain>
## Task Boundary

A fansub credit/attribution cue whose only untranslatable content is a short CJK
proper-name handle currently quarantines the entire file.

**Live incident (Job #6):** `Moon Knight - S01E01 ... .zh.srt` quarantined on
`validate.py` Check 9 at cue 437: translated text `Phụ đề dịch bởi: 虫二`. The model
correctly rendered the Chinese credit prefix into Vietnamese and left the fansub
handle `虫二` (a proper-name signature, untranslatable) in place. Check 9 treats ANY
CJK codepoint as an untranslated-source leak and kills the whole 437-cue file.

**Goal:** Let a *narrowly-detected* credit/attribution cue carry its residual short
CJK handle through Check 9, WITHOUT weakening Check 9's CJK strictness for real
dialogue (the consistency/leak moat).
</domain>

<decisions>
## Implementation Decisions

### Strategy — LOCKED: Exempt credit lines from Check 9
- Detect a credit/attribution cue and let its residual short CJK handle pass Check 9.
- Output ships the model's natural half-translated line (`Phụ đề dịch bởi: 虫二`) — VI
  prefix + untranslated proper-name handle. Preserves attribution; cue count unchanged.
- REJECTED alternatives (record why, do not revisit):
  - "Drop the cue entirely" — Check 1 (`validate.py:367`) requires
    `len(translated.lines) == len(source.lines)`; dropping desyncs the gate's
    source↔translated zip and would need a new cue-removal capability + re-index /
    sentinel-map ripple. Too invasive for this fix.
  - "Strip the CJK handle" — leaves a dangling `Phụ đề dịch bởi:` with no name.
  - "`raw` opaque passthrough" — would ship the FULL original Chinese line (more CJK),
    since `raw` emits source verbatim. Wrong tool: this leak is a half-translation,
    not a passthrough.

### Detection signature — must stay NARROW (moat guard)
The exemption fires ONLY when BOTH hold:
1. **Credit-keyword signal** present in the SOURCE cue OR the TRANSLATED cue. The
   Check 9 loop already has `src_sl` in scope (`validate.py:473`), so prefer the
   source cue (the original credit line is the most reliable signal). Suggested
   keyword set (case-insensitive; planner/executor may refine):
   - Vietnamese (translated prefix): `dịch bởi`, `phụ đề`, `biên dịch`, `người dịch`,
     `hiệu đính`, `vietsub`, `dịch thuật`
   - English: `subtitle`/`subtitles`, `translated by`, `translation by`, `sub by`,
     `subbed by`, `synced by`, `encoded by`, `ripped by`, `timing`
   - Chinese (source markers): `字幕`, `翻译`/`翻譯`, `字幕组`, `校对`/`校對`,
     `时间轴`/`時間軸`, `压制`/`壓制`, `后期`
2. **Short-handle guard**: the total count of CJK/Hangul/Kana codepoints in the
   TRANSLATED cue is ≤ a small threshold (suggest 8). A fully-untranslated dialogue
   line has many CJK chars → exceeds threshold → still quarantines. A 2-char handle
   like `虫二` passes.

**Conservative-by-design:** a credit line left FULLY untranslated (whole Chinese line,
many CJK chars) still quarantines — that signals a real translation failure, and the
narrow exemption must not mask it.

### Scope — LOCKED
- Touch ONLY Check 9 in `trezarr/translate/validate.py`. Do NOT alter Checks 1–8 or
  10–12, the `raw` passthrough path, or `engine.py`.
- Add the detector as a module-level helper + regex near the other per-cue detectors
  (`validate.py:81-193`), matching their docstring/comment density and naming style.
- Threshold: a module-level constant is acceptable (lean); a `settings`-backed value is
  optional (`validate_subdoc` already receives `settings`). Planner's discretion.

### Branch — LOCKED: new branch off main
- Already created: `fix/cjk-credit-line` (forked from `origin/main` @ 0f48a0b).
- Independent of the in-progress `fix/cross-episode-pronoun-carryforward` work.

### Claude's Discretion
