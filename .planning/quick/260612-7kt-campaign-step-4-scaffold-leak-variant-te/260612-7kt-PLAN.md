Campaign Step 4 — three VERIFIED findings from the Mode B audit (03_verdicts.md):

BLOCKER (Finding 1): The Pass-3 pronoun-hint parenthetical evades both the engine strip
(_LEAKED_HINT_RE) and gate Check 8 (HINT_SCAFFOLD_RE) when a weak model translates the
English labels into Vietnamese ("speaker says" → "tại hạ nói"; "addresses as" → "xưng hô").
E143 cue 148 shipped verbatim on-screen. Both the strip layer (engine.py) and the gate
backstop (validate.py Check 8) are anchored to English labels only.

HIGH (Finding 2): _upsert_term_in_session delegates to _merge_inferred_in_session for
existing rows. compute_field_changes only skips LOCKED fields — an unlocked
vietnamese_rendering is overwritten by every re-inference (20/53 MK rows churned in one
night; Khonshu→Khonsu contradicting a locked row). Fix: term-specific carry-forward in
_upsert_term_in_session (prior > inference for non-empty unlocked renderings), mirroring
the scy/ru6 address-map carry-forward ladder.

MEDIUM (Finding 3): analyze.py matches terms case-insensitively (.strip().lower()) but
_upsert_term_in_session queries with exact case-sensitive equality, creating duplicate
rows for 'judgment'/'Judgment', 'underworld'/'Underworld', etc. with competing renderings.
Fix: case-insensitive lookup at the upsert boundary using func.lower().

Purpose: Restore the closed-form "term-layer stability" invariant so IMP-04 re-run passes.
Output: All three fixes TDD-verified; 622+ tests green; no behavior change outside stated scope.
